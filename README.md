# MyGroup

Практическая работа по Android-разработке.

Тема: «Портал группы: студенты и оценки».

Приложение разработано на Kotlin с использованием XML-разметки.

## Возможности приложения

Приложение состоит из трех экранов:

- главный экран с вводом имени;
- список студентов;
- карточка выбранного студента с оценкой.

Для переходов между экранами используются явные Intent. Данные передаются с помощью putExtra().

## Использованные технологии

- Kotlin
- Android Studio
- XML
- LinearLayout
- RelativeLayout
- Intent
- Logcat
